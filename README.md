# Queue

## Описание проекта

Queue — это веб-приложение для управления очередями и записями пользователей. Проект разработан в рамках кейса от Т-Банка и занял 3 место в университетском хакатоне. 
Сервис решает проблему неопределенного порядка и неясного времени ожидания около стендов, существенно снижая нагрузку на организаторов и делая процесс посещения площадок прозрачным для участников.

### Основные функциональные возможности:
*   Просмотр доступных очередей
*   Запись и отслеживание места в очереди
*   Управление очередями для администраторов
*   Аутентификация и авторизация пользователей
*   Разделение функционала по ролям (пользователь/администратор)

## Технический стек

*   Язык (Backend): Go
*   Веб-фреймворк: REST API с собственной реализацией на Go
*   База данных: PostgreSQL
*   ORM: database/sql
*   Фронтенд: HTML, CSS, JavaScript
*   Веб-сервер: Nginx
*   Контейнеризация: Docker, Docker Compose

## Обязательные шаги для запуска проекта

1. Клонировать репозиторий и перейти в папку:
   ```bash
   git clone https://github.com/DexScen/Queue.git
   cd Queue
   ```

2. Настроить переменные окружения:
   Скопируйте `.env.example` в `backend/.env`:
   ```bash
   cp backend/.env.example backend/.env
   ```
   
   Пример содержимого `.env`:
   ```env
   DB_HOST=postgres
   DB_PORT=5432
   DB_USER=postgres
   DB_PASSWORD=postgres
   DB_NAME=queue_db
   PORT=8080
   ```

---

## Запуск через Docker Compose

1. Запустить все сервисы:
   ```bash
   docker-compose up --build
   ```
   
   После успешного запуска:
   * Frontend доступен по адресу: `http://localhost:80`
   * Backend API доступен по адресу: `http://localhost:8080`

## Структура БД

Инициализация базы данных осуществляется через скрипт `PostgreSQL/init.sql` и включает следующие таблицы:

| Таблица | Назначение |
|---------|-----------|
| `users` | Информация о пользователях (логин, пароль, роль) |
| `games` | Описания очередей/игр (название, описание, макс. участников) |
| `queue` | Участники очередей (пользователь, очередь, время записи, позиция) |

---

## Основные REST endpoints

| Метод | Путь | Описание |
|-------|------|---------|
| `GET` | `/api/games` | Получить список всех очередей |
| `GET` | `/api/games/:id` | Получить информацию об очереди |
| `POST` | `/api/games/:id/join` | Присоединиться к очереди |
| `POST` | `/api/auth/register` | Регистрация нового пользователя |
| `POST` | `/api/auth/login` | Авторизация пользователя |
| `GET` | `/api/users/:login/games` | Получить список очередей пользователя |

---

## Архитектура проекта

Проект состоит из нескольких независимых сервисов:

*   **Backend** — Go-сервер с REST API, обработчики запросов, middleware для авторизации
*   **Frontend** — веб-интерфейс с разделением по ролям (пользователь/администратор)
*   **PostgreSQL** — база данных с предзагруженной схемой
*   **Nginx** — веб-сервер для фронтенда
